SPIDER WEB SWING PROTOTYPE
===========================

Godot 4 project. No external assets are required.

Controls:
WASD = move
SPACE = jump
Left Mouse = attach/release web swing
Right Mouse = web attack

Open project.godot in Godot 4.x and press F6/F5.

This prototype uses Godot's built-in 3D meshes and procedural city geometry,
so there are no AI-generated images or downloaded asset packs in the project.

For an itch.io upload, export the project from Godot using Project > Export.
Do not distribute copyrighted Spider-Man branding/assets unless you have the
rights to do so. A fan-made project should clearly state that it is unofficial.
